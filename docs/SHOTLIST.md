# Screenshots, how they're captured

Screenshots are **generated by a reproducible script**, not captured by hand, so
they always match the live app. The scripts live in the main app repo at
`scripts/docs-shots/` and write PNGs (1280px wide, 2× retina) straight into
`docs/public/screenshots/`.

## Regenerate everything

From the **app** repo (`appliedteaming/`), with `.env` present (needs
`SUPABASE_SERVICE_ROLE_KEY` + the Supabase URL/anon key):

```bash
node scripts/docs-shots/capture.mjs            # profile, dashboard, checkpoints, artifacts, team story
node scripts/docs-shots/capture-tabs.mjs       # Class / Team / Personal tab sections
node scripts/docs-shots/capture-onboarding.mjs # the 4-step onboarding wizard (resets a test account)
node scripts/docs-shots/capture-misc.mjs       # sign-in, atlas, tab bar, join
```

Each script signs in as a seeded **test account** by minting a session through
the Supabase admin API (a magic-link token verified server-side, no passwords),
then drives Playwright to the real production pages. Re-running overwrites the
PNGs in place, so a docs refresh after a UI change is one command.

## The image set

Grouped by where they appear in the guide:

- **Getting started**: `signin`, `onboarding-basics`, `onboarding-resume`,
  `onboarding-review`, `onboarding-background`, `onboarding-direction`,
  `join-code`, `course-new`
- **Living profile**: `home-graph`, `home-atlas`
- **Course dashboard**: `course-dashboard`, `course-tabs`, `finishing`
- **Check-ins**: `checkpoint-charter` (start), `checkpoint-form` (mid/end),
  `checkpoint-carryforward`, `checkpoint-peer`, `checkpoint-end`
- **Class view**: `class-overlay`, `class-identity`, `class-storyboard`
- **Team view**: `team-report`, `team-synthesis-section`, `team-synthesis`
- **Personal view**: `personal-growth`, `personal-feedback`, `artifacts-roadmap`
- **Artifacts**: `artifact-record`, `artifact-interview-stories`, `artifact-growth-summary`

Faculty and explore shots (`faculty-*`, `explore-*`) are captured the same way
against those routes; extend the scripts as those pages change.
