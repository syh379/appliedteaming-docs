# 3 · Joining a class

**What it is**: how a student joins your course. There are two ways, and you choose which to hand out.

## Option A: a join code

<div class="steps">

1. You give the class a short **join code** (see [faculty setup](/faculty/setup)).
2. The student adds a course and enters the code, or opens a link you share.
3. They're placed into the course and, if you've set up teams, onto their team automatically.

</div>

![Joining a course with a code.](/screenshots/join-code.png)
*The "Join with a code" tab, the student pastes the code you shared. Team assignment happens behind the scenes.*

## Option B: search the catalog

Students can also add a course by searching the **Berkeley course catalog** and picking it. Pilot courses (like Info 213) route into the full team experience; other courses become a lightweight personal record.

![Adding a course from the catalog.](/screenshots/course-new.png)
*The two ways to add a course: join with a code, or search the catalog.*

## Notes

- **Pilot courses** run the full team experience: check-ins, the Class/Team/Personal dashboard, and artifacts.
- **Non-pilot courses** a student self-adds are kept light: a simple record and a short retrospective, no team machinery.
- A student only ever sees **their own** team's private information; classmates on other teams see the shared class view but not each other's team reports.
