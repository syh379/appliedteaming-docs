# The course dashboard

**What it is**: the home base for a course. It's designed so a student always knows four things at a glance: **how far am I, what's my next step, what have I got so far, and what's still to unlock.**

## What the student sees

At the top, a **hero** (course name, term, progress) and the **checkpoint schedule**.

![The course dashboard header and schedule.](/screenshots/course-dashboard.png)
*The schedule shows a progress bar, "done / total," and a bright next-step button.*

- **Progress**: a bar and a "X of N done" count.
- **Next step**: a prominent button that jumps straight to the next check-in (or a "you've completed every checkpoint" note at the end).
- **The schedule**: every checkpoint, marked done / current / upcoming, with due dates.

## The three tabs

Below the schedule, the insights live under three tabs. **Everyone sees the same Class and Team backdrop, but their own Personal layer.**

![The Class / Team / Personal tabs.](/screenshots/course-tabs.png)
*Three views of the same course: Class, Team, and Personal.*

- **[Class](/course/class-view)**: the whole cohort, anonymized. Updates live.
- **[Team](/course/team-view)**: the student's team, once everyone's submitted.
- **[Personal](/course/personal-view)**: the student's own growth over time and the feedback they've received.

## Notes

- The hero and schedule stay pinned above the tabs, so the "what's next" is always in view.
- The dashboard is the same for every pilot course, only the number of checkpoints differs.
