# Class view

**What it is**: the whole cohort, anonymized. It's the one view that **updates live**, the moment any classmate submits. Three things live here.

## 1 · The class picture

An aggregate of the cohort's **roles** and how the **core attributes** are going: bars and thumb tallies, name-free.

![The class picture, roles and attributes across the cohort.](/screenshots/class-overlay.png)
*"Your class right now", patterns only, never anyone's answers by name.*

## 2 · The class identity graph

Everyone's individual profile maps, **overlaid into one**, across the same six dimensions. The domains more classmates share grow **bigger and brighter**; a student's own domains are highlighted.

![The aggregated class identity graph.](/screenshots/class-identity.png)
*"Your class, as one identity", a shared picture of what the cohort is building.*

## 3 · The class storyboard

The anonymized stories classmates chose to share, with a short AI reading of what connects them.

![The class storyboard.](/screenshots/class-storyboard.png)
*Author-less stories + surfaced themes, a picture of who's in the room.*

## Notes

- **Everything here is k-anonymous**: only patterns shared by **at least three** classmates appear, so nothing traces back to one person.
- No names, ever. No scores or "good vs. bad" labels, only descriptive patterns.
- This view keeps filling in continuously as the class checks in; there's no waiting.
