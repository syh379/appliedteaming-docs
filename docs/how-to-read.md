# How to read this guide

Each page follows the same shape so it's easy to scan.

- **What it is** - a one-line description of the screen.
- **What the student does** - numbered steps, in plain language.
- **What the student sees** - a screenshot, with the important parts called out.
- **Notes** - anything worth knowing (privacy, timing, what unlocks when).

## The demo account

Every screenshot in this guide was captured from a **real seeded student account** in a live pilot course (**Info 213**, a UX design class), so what you see is exactly what a student sees — the same map, check-ins, teammates, and classmates.

::: info Following along yourself
Ask your Applied Teaming contact for the demo sign-in, open the app, and you can retrace every step in this guide.
:::

## A note on wording

Different courses use different names for the same thing - a "Team Charter" and a "start-of-semester survey" are the same **checkpoint**. Throughout this guide we use the plain words **check-in** and **checkpoint** interchangeably.
